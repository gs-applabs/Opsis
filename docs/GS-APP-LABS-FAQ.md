# Opsis — FAQ / Συχνές ερωτήσεις

**Focus / Αντικείμενο:** Desktop personalization / Εξατομίκευση επιφάνειας εργασίας

## Where do I download it? / Πού το κατεβάζω;

[Latest stable published release](https://github.com/gs-applabs/Opsis/releases/latest). Select the official installer and matching SHA-256 file if provided. Read the requirements, limitations and upgrade notes. A hash is an integrity check, not a signature or proof of safety. Do not bypass OS warnings.

## How do I get started? / Πώς ξεκινάω;

Start with display and theme settings; review plugin compatibility for the current host release.

## What are the limitations? / Ποιοι είναι οι περιορισμοί;

The wallpaper engine and Windows shell features can depend on WebView2, display configuration and the running Windows build. Test a reversible change first. / Τα φόντα και οι λειτουργίες κελύφους εξαρτώνται από WebView2, οθόνες και έκδοση Windows. Δοκίμασε πρώτα μια αναστρέψιμη αλλαγή.

## Where do I find screenshots? / Πού βρίσκω εικόνες;

[Actual Windows CI screenshot gallery](product-snapshots/README.md). Some views use demonstration data. Visual tests are not full functional acceptance tests.

## Can I report a bug or suggest a feature? / Μπορώ να αναφέρω σφάλμα ή να προτείνω δυνατότητα;

[Open an issue](https://github.com/gs-applabs/Opsis/issues/new/choose). Include your app and Windows versions and steps to reproduce. Redact personal data, credentials and confidential files.

## What is planned? / Τι σχεδιάζεται;

Broader mixed-DPI and multi-monitor coverage; accessible settings; reproducible UI demonstrations.

This is a non-binding direction, not a promised release date. / Ενδεικτική κατεύθυνση, χωρίς δεσμευτική ημερομηνία.
