- Source: `release/2.8.0.2510` (no common ancestor with old `main`).
- Integration: `feat/p0-from-2.8.0.2510` → PR #6 targeting the release branch.
- Do **not** merge changes from the obsolete branch using a plain git merge.
- This branch has not been compiled or executed on Windows in the current session.

## Implemented
1. Weather overlay: white city, time, date, temperature, wind and source text protected against theme overrides.
2. Explorer: opt-in productivity settings, capture original HKCU registry values once, restore action.
3. Taskbar: Windows 11 minimal/standard presets, capture/restore actual original values, direct Start and Taskbar native settings links. These are native preferences, **not** a StartAllBack replacement.
4. Hot Corners: four configurable corners, 700ms dwell, UI-thread timer, no global hooks, disabled by default, not started in safe mode; settings loaded from Opsis store.
5. Mouse Effects: native Windows cursor trails using SystemParametersInfo, prior value saved, explicit restoration; native Windows mouse configuration link.
6. Screen Saver: Windows screen-saver settings panel and preview of configured .scr only if it is within the real Windows System32 directory.
7. Appearance profile preview: non-mutating text summary of Explorer/Taskbar presets in the Personalization page.

## Safety / release gating
- All controls require user action except Hot Corners, which only starts if explicitly enabled; default mapping is None.
- No Explorer executable patches, DLL injection, forced Explorer restart, admin permissions or use of StartAllBack executable.
- Existing Windows version-dependent shell keys may be ignored in some builds: this must be tested.
- Do not mark release complete or ship installer until Windows validation and regression tests have passed.
