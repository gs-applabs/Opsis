# Πάροχοι καιρού — συγκριτικός πίνακας για απόφαση χρήστη (plan 0Β.5)

Κατάσταση: **δεν έχει αλλάξει κώδικας.** Σήμερα το Opsis χρησιμοποιεί **Open-Meteo** (πρόβλεψη + geocoding) με εφεδρικό το wttr.in (`src/Widgets/WeatherService.cs`).
Ο πίνακας βασίζεται σε αναζητήσεις στο web (όχι από μνήμη). Ό,τι δεν επιβεβαιώθηκε από επίσημη σελίδα σημειώνεται ως **ΠΡΟΣ ΕΠΑΛΗΘΕΥΣΗ**.

| Πάροχος | Κάλυψη | Κλειδί API | Όροι / όρια (επιβεβαιωμένα) | Ακρίβεια | Σχόλιο για το Opsis |
|---|---|---|---|---|---|
| **Open-Meteo** (σήμερα) | Παγκόσμια | Όχι | Δωρεάν μόνο για **μη εμπορική** χρήση· <10.000 κλήσεις/ημέρα, 5.000/ώρα, 600/λεπτό· αναφορά πηγής CC BY 4.0 ([όροι](https://open-meteo.com/en/terms)) | Συνδυάζει εθνικά μοντέλα (GFS, ICON, AROME, ECMWF IFS, JMA)· η ακρίβεια είναι αυτή των μοντέλων — η «κορυφαία ακρίβεια» είναι δήλωση του ίδιου του έργου, **όχι ανεξάρτητη επαλήθευση** | Ήδη ενσωματωμένο, χωρίς κλειδί, με geocoding. ## Πρόταση (προς απόφαση)
1. **Μένει ο Open-Meteo ως βασικός** (παγκόσμιος, χωρίς κλειδί, ήδη δοκιμασμένος) και διατηρείται η αναφορά πηγής (attribution) στις ρυθμίσεις/About.
2. **Προαιρετικός δεύτερος πάροχος ανά περιοχή** πίσω από ενιαίο εσωτερικό interface (`IWeatherProvider`): MET Norway για Ευρώπη, NWS για ΗΠΑ — μόνο αν ο χρήστης θέλει ακριβέστερο τοπικά. Για να κριθεί «ακριβέστερος» χρειάζεται **μέτρηση σε πραγματικές πόλεις** (σύγκριση πρόβλεψης με παρατήρηση), όχι ισχυρισμοί παρόχων.
3. Απόφαση που χρειάζομαι: **(α)** μένουμε μόνο Open-Meteo, ή **(β)** προσθέτουμε MET Norway/NWS ως επιλογή ανά περιοχή.

## Ανίχνευση τοποθεσίας (σχεδιασμός, δεν υλοποιήθηκε)
- Opt-in με ρητή συναίνεση· Windows Location API **ή** χειροκίνητη πόλη (σήμερα υπάρχει επιλογή πόλης με geocoding).
- Στρογγυλοποίηση συντεταγμένων (π.χ. 2 δεκαδικά ≈ 1 km) πριν σταλούν· **μόνιμη αποθήκευση μόνο πόλης/περιοχής**, ποτέ ακριβούς θέσης.
- Αποστολή: μόνο στον πάροχο καιρού, μέσω HTTPS· κανένα κλειδί στον client (οι πάροχοι αυτοί δεν χρειάζονται)· ρύθμιση απενεργοποίησης και διαγραφής.
- Τι στέλνεται και πού καταγράφεται εδώ: `latitude, longitude` (στρογγυλοποιημένα) → `api.open-meteo.com` (και, αν επιλεγεί, `api.met.no` / `api.weather.gov`)· όνομα πόλης για αναζήτηση → `geocoding-api.open-meteo.com`.
