# Δοκιμή των νέων DeskContainers (2.6.0-beta) — με ασφάλεια

Η δοκιμή τρέχει από **ξεχωριστό φάκελο** (`C:\w\Opsis-2.6.0-beta-portable`) με **δικό της φάκελο δεδομένων** (`data\`).
Το εγκατεστημένο Opsis 2.4.6.1 και τα δεδομένα του (`%AppData%\Opsis`) **δεν αγγίζονται**. Δεν υπάρχει installer, δεν γράφεται τίποτα στο registry.

## Πριν ξεκινήσεις
1. Κλείσε το εγκατεστημένο Opsis (δεξί κλικ στο εικονίδιο του tray → Έξοδος) και, αν τρέχει, το `OpsisContainers.exe` του (Task Manager → Λεπτομέρειες). Αλλιώς θα βλέπεις δύο σετ containers και θα συγκρούονται τα hotkeys.
2. Αν θες, κράτα ανοιχτό ένα παράθυρο PowerShell/CMD για ό,τι χρειαστεί.

## Εκκίνηση
1. Διπλό κλικ στο `C:\w\Opsis-2.6.0-beta-portable\Start-Opsis-TEST.bat`.
2. Η ρύθμιση `UseNativeContainers` και η GPU glass είναι **ήδη ενεργές** στο `data\settings.json`. Μετά από ~10 δευτερόλεπτα πρέπει να εμφανιστεί ένα container «Test» (πορτοκαλί τίτλος) με Notepad, Calc, Charmap.

## Τι να παρατηρήσεις
- **Διαφάνεια / glass / ζωντανό φόντο:** το σώμα του container είναι διάφανο και θολώνει/διαθλά το φόντο. Αν έχεις κινούμενο wallpaper, πρέπει να φαίνεται να κινείται πίσω από το γυαλί.
- **Τίτλος:** δικό του χρώμα, ύψος και γραμματοσειρά (όχι του πλαισίου). Διπλό κλικ στον τίτλο = ρολό (roll-up), ξανά = ξεκύλισμα.
- **Drag & drop:** σύρε ένα αρχείο από την Εξερεύνηση μέσα στο container → προστίθεται ως *συντόμευση* (το αρχείο δεν μετακινείται/αντιγράφεται). Σύρε εικονίδιο μέσα στο container για αναδιάταξη. Δεξί κλικ σε εικονίδιο → «Remove from container» αφαιρεί μόνο τη συντόμευση.
- **Μετακίνηση / μέγεθος:** σύρε τον τίτλο (κάνει snap στις άκρες), σύρε τη γωνία κάτω-δεξιά για μέγεθος.
- **Πληκτρολόγιο:** κάνε κλικ στο container και πάτα βέλη / Home / End / Enter (άνοιγμα) / Delete (αφαίρεση συντόμευσης).
- **Win+D:** πάτα Win+D και μετά ξανά. Σημείωσε αν το container μένει πάνω από την επιφάνεια ή χάνεται (το z-order δεν έχει ακόμη δοκιμαστεί σε πραγματικό desktop — αυτό είναι ένα από τα πράγματα που ψάχνουμε).
- **Επανεκκίνηση Explorer:** Task Manager → Windows Explorer → Επανεκκίνηση. Το container πρέπει να παραμείνει / να επανεμφανιστεί.
- **Δύο οθόνες / DPI:** αν έχεις, μετακίνησε το container σε άλλη οθόνη και σημείωσε μέγεθος/κείμενο.
- **Πόροι:** δες CPU/GPU του Opsis στο Task Manager σε ηρεμία (πρέπει να είναι κοντά στο 0%).

Γράψε μου ό,τι δεις (ακόμα και «όλα εντάξει»).

## Αν κάτι πάει στραβά — ΔΙΑΣΩΣΗ (πάντα διαθέσιμη)
1. **Διπλό κλικ στο `Rescue-Desktop.bat`** (στον ίδιο φάκελο). Κλείνει **μόνο** το δοκιμαστικό Opsis (όχι το εγκατεστημένο) και επαναφέρει τα εικονίδια της επιφάνειας.
2. Αν δεν δουλεύει το .bat, άνοιξε PowerShell και τρέξε:

   ```powershell
   Get-Process Opsis,OpsisContainers | Where-Object { $_.Path -like '*Opsis-2.6.0-beta-portable*' } | Stop-Process -Force
   $env:OPSIS_APPDATA = 'C:\w\Opsis-2.6.0-beta-portable\data'
   & 'C:\w\Opsis-2.6.0-beta-portable\app\Opsis.exe' --restore-desktop-icons
   ```
3. Αν τα εικονίδια εξακολουθούν να λείπουν: δεξί κλικ στην επιφάνεια → Προβολή → «Αυτόματη τακτοποίηση εικονιδίων» (ενεργοποίηση και μετά απενεργοποίηση). Ως τελευταία λύση: Task Manager → Windows Explorer → Επανεκκίνηση.
4. Για πλήρη επαναφορά της δοκιμής: κλείσε το δοκιμαστικό Opsis και σβήσε τον φάκελο `C:\w\Opsis-2.6.0-beta-portable`. Το εγκατεστημένο Opsis δεν επηρεάζεται.

## Τι έχει ελεγχθεί ήδη (αυτόματα)
- Το δοκιμαστικό Opsis ξεκινά με το δικό του `data\`, φορτώνει το container και απαντά στο pipe (`Opsis.exe --containers list`).
- Τα νέα native containers **δεν κρύβουν και δεν μετακινούν εικονίδια της επιφάνειας** (το «κρύψιμο αρχικών» δεν είναι υλοποιημένο ακόμη).
- Το quick-hide του Opsis (διπλό κλικ στην επιφάνεια) *κρύβει* εικονίδια μετακινώντας τα εκτός οθόνης και κρατά τις θέσεις σε αρχείο κατάστασης. Δοκιμάστηκε: κρύφτηκαν 162 από 166 εικονίδια, η διεργασία **σκοτώθηκε** χωρίς καθαρισμό, και η εντολή `--restore-desktop-icons` τα έβαλε **ακριβώς στις ίδιες θέσεις** (σύγκριση πριν/μετά ίδια). Η κανονική έξοδος και η επόμενη εκκίνηση κάνουν επίσης αυτόματη επαναφορά.
- Kill του δοκιμαστικού Opsis: τα παράθυρα των containers εξαφανίζονται, το εγκατεστημένο Opsis δεν επηρεάζεται.

## Γνωστά όρια της beta
Z-order σε σχέση με το επίπεδο εικονιδίων/wallpaper, Win+D, Explorer restart, πολλαπλά DPI, screen reader — όλα **άγνωστα μέχρι να δοκιμαστούν από σένα**. Δεν υπάρχει ακόμη UI για κανόνες/snapshots, ούτε global hotkey.
