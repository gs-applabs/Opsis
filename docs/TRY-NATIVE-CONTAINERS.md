# Δοκιμή των νέων DeskContainers (2.6.0 beta) — με ασφάλεια

Από την 2.6.0 beta τα DeskContainers είναι ο **νέος πυρήνας μέσα στο Opsis.exe** (το παλιό WPF `OpsisContainers.exe` αφαιρέθηκε). Η δοκιμή τρέχει από **ξεχωριστό φάκελο** (`Opsis-2.6.0-beta-portable`, η διαδρομή δόθηκε στο chat· παρακάτω «ο φάκελος») με **δικό της φάκελο δεδομένων** (`data\`). Το εγκατεστημένο Opsis και τα δεδομένα του (`%AppData%\Opsis`) **δεν αγγίζονται**.

## Πριν ξεκινήσεις
1. Κλείσε το εγκατεστημένο Opsis (tray → Έξοδος). Αλλιώς θα συγκρούονται τα hotkeys και θα βλέπεις διπλά widgets/wallpaper.
2. Το δοκιμαστικό ξεκινά με δικά του δεδομένα: ένα container «Test» με Notepad, Calc, Charmap.

## Εκκίνηση
Διπλό κλικ στο `Start-Opsis-TEST.bat` μέσα στον φάκελο. Σε ~10 δευτερόλεπτα εμφανίζεται το container (πορτοκαλί τίτλος). Ρυθμίσεις: πλευρικό μενού → **DeskContainers**.

## Τι να παρατηρήσεις
- **Γυαλί / διαφάνεια / ζωντανό φόντο:** το σώμα του container είναι διάφανο και δείχνει το φόντο πίσω του (με κινούμενο wallpaper πρέπει να φαίνεται να κινείται). Το glass ενεργοποιείται από Ρυθμίσεις → Εμφάνιση → Για προχωρημένους («GPU glass»).
- **Θέση πάνω από την επιφάνεια:** το container πρέπει να είναι **πάνω από τα εικονίδια/wallpaper αλλά κάτω από τα παράθυρα** των εφαρμογών (δεν μένει πάνω από ό,τι δουλεύεις).
- **Τίτλος:** δικό του χρώμα, ύψος, γραμματοσειρά (DeskContainers → Container). Διπλό κλικ στον τίτλο = ρολό.
- **Drag & drop:** σύρε αρχείο από την Εξερεύνηση μέσα → προστίθεται ως *συντόμευση* (το αρχείο δεν μετακινείται). Σύρε εικονίδιο μέσα στο container για αναδιάταξη. Διπλό κλικ σε εικονίδιο = εκκίνηση. Δεξί κλικ → «Remove from container» αφαιρεί μόνο τη συντόμευση.
- **Πληκτρολόγιο:** κλικ στο container, βέλη / Home / End / Enter / Delete.
- **Συντομεύσεις:** Ctrl+Alt+Shift+N = νέο container, Ctrl+Alt+Shift+H = απόκρυψη/εμφάνιση όλων. Tray → DeskContainers.
- **Στιγμιότυπα διάταξης:** DeskContainers → Στιγμιότυπα (αποθήκευση/φόρτωση).

## Βήματα που χρειάζονται ΕΣΕΝΑ (δεν γίνονται αυτόματα)
**Win+D:** άνοιξε 2-3 παράθυρα, πάτα Win+D. Το container πρέπει να μείνει ορατό πάνω από την επιφάνεια. Πάτα ξανά Win+D: τα παράθυρα επιστρέφουν και το container πάλι κάτω από αυτά.
**Επανεκκίνηση Explorer:** Task Manager → Windows Explorer → Επανεκκίνηση. Μέσα σε 1-2 δευτερόλεπτα μετά την επιστροφή της επιφάνειας το container πρέπει να φαίνεται ξανά στη θέση του.
**Δύο οθόνες / διαφορετικό DPI:** σύρε το container στην άλλη οθόνη, μετά κλείσε/ξανάνοιξε το δοκιμαστικό: πρέπει να ξαναβρεθεί στην ίδια οθόνη με σωστό μέγεθος (γράμματα όχι θολά/κομμένα).
**Κλείδωμα οθόνης (Win+L) και UAC:** κλείδωσε και ξεκλείδωσε· το glass δεν πρέπει να μείνει «παγωμένο».
Γράψε μου τι είδες (ακόμα και «όλα εντάξει»).

## Αν κάτι πάει στραβά — ΔΙΑΣΩΣΗ (πάντα διαθέσιμη)
1. Διπλό κλικ στο `Rescue-Desktop.bat` στον φάκελο: κλείνει **μόνο** το δοκιμαστικό Opsis και επαναφέρει τα εικονίδια της επιφάνειας.
2. Αν δεν δουλεύει, στο PowerShell:
   ```powershell
   Get-Process Opsis | Where-Object { $_.Path -like '*Opsis-2.6.0-beta-portable*' } | Stop-Process -Force
   cd <ο φάκελος της δοκιμής>
   $env:OPSIS_APPDATA = (Resolve-Path .\data)
   & .\app\Opsis.exe --restore-desktop-icons
   ```
3. Αν τα εικονίδια λείπουν ακόμα: δεξί κλικ στην επιφάνεια → Προβολή → «Αυτόματη τακτοποίηση εικονιδίων» (ενεργοποίηση και μετά απενεργοποίηση). Τελευταία λύση: Task Manager → Windows Explorer → Επανεκκίνηση.
4. Πλήρης επαναφορά: κλείσε το δοκιμαστικό και σβήσε τον φάκελο της δοκιμής. Το εγκατεστημένο Opsis δεν επηρεάζεται.

## Τι έχει ελεγχθεί ήδη (αυτόματα)
- Φόρτωση του container από τα δεδομένα, απάντηση του pipe (`Opsis.exe --containers list`).
- Τα containers **δεν κρύβουν και δεν μετακινούν εικονίδια** της επιφάνειας. Το quick-hide (διπλό κλικ στην επιφάνεια) κρύβει εικονίδια και δοκιμάστηκε: κρύφτηκαν 162/166, kill χωρίς cleanup, `--restore-desktop-icons` τα επανέφερε **στις ίδιες θέσεις**.
- Z-order σε πραγματική αλυσίδα παραθύρων: κάτω από κανονικό παράθυρο, πάνω από την επιφάνεια, επανατοποθέτηση μετά από SendToBack.
- Αναβάθμιση 2.4.6.2 → 2.6.0 beta με ξεχωριστό installer δοκιμής (άλλο AppId, δικός του προσωρινός φάκελος, χωρίς admin): το νέο exe 2.6.0, ο φάκελος `containers\` του παλιού κινητήρα διαγράφηκε, η εγγραφή απεγκατάστασης έδειξε «2.6.0 beta», και η απεγκατάσταση καθάρισε όλα· το πραγματικό σου Opsis δεν αγγίχτηκε.
- Εισαγωγή δεδομένων 2.4.x (μόνο ανάγνωση) στην πρώτη εκκίνηση: το προφίλ Default γίνεται η διάταξη, τα άλλα προφίλ γίνονται στιγμιότυπα· ο παλιός φάκελος μένει ανέγγιχτος (2 tests).

## Γνωστά όρια της beta (✗ λείπει σε σχέση με το παλιό)
Tabs/portals/σημειώσεις μέσα στα containers, απόκρυψη των αρχικών εικονιδίων της επιφάνειας όταν τα ρίχνεις μέσα, Spot Search (Ctrl+`), hotkeys προφίλ, αυτόματο οργάνωμα με κανόνες τύπου/επέκτασης, backups, εφέ εκκίνησης/λάμψης. Βλ. `docs/CONTAINERS_EQUIVALENCE.md`.
