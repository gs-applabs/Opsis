# Signature Composition preview

The ordinary Opsis build is unchanged. The opt-in build flag EnableSignatureComposition=true switches only the shared GlassPaneBinder implementation to the reconstructed Opsis.UI.Composition library, with one renderer per UI thread. Existing material settings and hardware/activity decisions are retained. No legacy pane is created for the same binder. DeskStrip uses its separate legacy path until a dedicated migration is validated; other callers not using GlassPaneBinder are not switched.

Build from Opsis.UI commit 4b168dadf3eada5ec6883883ba90c52d4336da74 in a separate checkout. Run tools/Build-SignaturePreview.ps1 -SignatureUiRoot <absolute path>. Requires Windows x64, Visual C++ and Windows SDK, .NET 11, and git. The script builds native code, runs both UI and composition tests, then builds the preview into artifacts/SignaturePreview. This is a build gate, not a published installer. A normal build does not require that checkout.

For active glass, the wallpaper window obtains its own WebView2 preview, never the desktop screenshot, at most once every 2 seconds per active monitor, only on demand. It caches a reduced image in memory and supplies a crop in monitor coordinates. No disk I/O is added for frames. The preview includes the wallpaper's own overlays and is not a full capture of windows behind a pane. Off-monitor, paused and unavailable frames fall back to tint; cross-monitor panes are not sampled. This path does not support live high-FPS refraction, HDR, or a physical glass simulation. CapturePreview PNG encode/decode has real cost: verify CPU and latency before increasing frequency.

Test plan: verify all Widgets using GlassPaneBinder, show/hide, dragging, DPI, monitor edges, lock/unlock, battery saver, fullscreen, device loss, material change, active and paused wallpaper, input passthrough and topmost z-order. Check no duplicate panes and no stale bitmap after move. Compare GDI handles, working set, CPU and GPU utilization to the legacy build. Keep original installer/DLL untouched until validated. Do not distribute the preview to plugins.
