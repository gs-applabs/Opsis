# R26 review preview installer
This temporary test installer has a different AppId because the original OPSIS 100 add-on installer source and identity are unavailable. It installs only data in widgets/wallpaper/scenes/europe-preview, with explicit preview receipts, not production approvals. It never overwrites Opsis.exe, Greek scenes, or the original 100. The R26 host build is required for preview Gallery discovery; do not replace an existing main installation blindly with the development host. For a safe test use a separate copy of the R26 published host and select that folder in the installer. Every included scene has aligned 1080p preview files; original native masters remain in R22/R23/R25 artifacts. Unusable masks and missing cities are excluded and listed in PREVIEW-REPORT.json. No claims of final geographic or legal review. Production release remains gated by stage-approved-europe.py and the original add-on installer identity. The runtime dynamically grades the master; five pregraded assets are included for inspection, not used for crossfades.
