# R24 — optional European capitals installer integration

The 49 cities (Athens excluded; existing Greek pack untouched) use the existing native Weather mode. Runtime data goes under `{app}/widgets/wallpaper/scenes/europe/eu-<city>/`. This is an installer payload extension, NOT a separate executable installer. The standalone OPSIS 100 Wallpapers installer source was not located in this repository. Insert `europe-files.iss` inside its existing [Files] section and set EuropePayload to the validated staging directory. Preserve the original 100 themes, installer identity and uninstall metadata. Do not include the review folders or originals in the installer.

Before building the release, each city needs reviewed geometry/viewpoint, rights and attribution (including derivatives), fine skyline mask, lighting and Windows renderer verification. Maintain native archival masters separately. Runtime images may be downsampled to 1920–3840 pixels, never upscaled. The L-mode mask and all five RGBA phases must match runtime master exactly. The native engine dynamically grades the master and replaces the sky; it does not currently crossfade the pregraded phase files. Selection explicitly sets the existing shared weather location (which can affect the weather widget). The existing 3D approximation is disabled for approved photo cities.

Create approvals.json containing {"cities":[{"id":"eu-madrid","status":"approved","reviewer":"actual reviewer","checks":{"geography":true,"viewpoint":true,"license":true,"skyline":true,"lighting":true,"renderer":true},"sha256":{"master.webp":"actual sha256", ...}}]}. No synthetic or implied approvals. Each directory in --source must contain master.webp, sky-mask.png, poster.jpg, attribution.json, dawn/day/golden/blue/night.webp. Attribution fields: source_page, artist, license, license_url, changes, timezone.

```
python stage-approved-europe.py --catalog europe-capitals.json --approvals approvals.json --source approved --dest payload
```

The full release refuses fewer than 49 approvals, duplicate IDs, invalid hashes, mismatched alpha, and abnormal masks. --partial-test is for local development, not distribution. Install into the existing add-on destination, run Windows WebView2 smoke and install/upgrade/uninstall tests (verify old 100 and Greek themes), then compile and publish the original add-on installer. Runtime discovery uses installer-owned approval receipts and existence checks (not a signature or per-frame cryptographic verification). No approved assets or production installer were generated by this source commit.
