# Opsis Desktop Customization

Αυτόνομη έκδοση για Windows x64 που βασίζεται στον πηγαίο κώδικα Opsis 2.6.0. Η έκδοση ανοίγει με το skin **Studio**, με μόνιμη πλοήγηση σε ενότητες αριστερά και ενιαία αναζήτηση επάνω. Από **Θέμα → Skin παραθύρου** μπορείς να διαλέξεις την κλασική εμφάνιση 2.6.0.

## Εκτέλεση

1. Κλείσε το αρχικό Opsis από την περιοχή ειδοποιήσεων, ώστε να ελευθερωθούν οι συντομεύσεις και ο έλεγχος της επιφάνειας εργασίας.
2. Το παρόν πακέτο **2.7.7.2403** είναι πηγαίος κώδικας, όχι έτοιμος installer. Για νέο Windows build χρησιμοποίησε το `installer/build.ps1` με .NET 11 SDK και Inno Setup 7. Ο προηγούμενος installer `OpsisSetup-2.7.7.2402.exe` δεν περιέχει τις νέες αλλαγές.
3. Χρειάζεται .NET 11 Desktop Runtime x64. Το WebView2 Runtime χρησιμοποιείται για τα wallpapers και τα widgets που αποδίδονται ως ιστοσελίδες.

Η εφαρμογή αποθηκεύει τις δικές του ρυθμίσεις στο `%APPDATA%\Opsis Studio` και χρησιμοποιεί ξεχωριστή εγγραφή αυτόματης εκκίνησης. Το πακέτο είναι φορητό. Η ενεργοποίηση της αυτόματης εκκίνησης χρησιμοποιεί τη διαδρομή όπου αποσυμπίεσες την εφαρμογή. Το Studio δεν έχει δικό του κανάλι αυτόματων ενημερώσεων.

## Λειτουργίες

- **Εμφάνιση**. Wallpaper, θέματα και εξατομίκευση Windows. Η ρύθμιση κλειδώματος ανοίγει την αντίστοιχη σελίδα των Windows. Ο επιλογέας GIF μπορεί να δείξει την κίνηση στην προεπισκόπηση και να εφαρμόσει επιλεγμένο στατικό καρέ στην οθόνη κλειδώματος.
- **Επιφάνεια**. Widgets, DeskContainers, DeskStrip και DeskZones. Τα containers χρησιμοποιούν τον εγγενή μηχανισμό της 2.6.0.
- **Έλεγχος**. Αυτοματισμοί, προφίλ, παρακολούθηση συστήματος και διαχείριση ήχου όταν ανιχνεύεται η εγκατάσταση του Opsis Media Suite.
- **Σύστημα**. Ρυθμίσεις, πληροφορίες έκδοσης και συμβατότητα με το συμβόλαιο προσθέτων της 2.6.0.
- **Desk Music Visualizer**. Έχει ξεχωριστή καρτέλα στο κύριο παράθυρο. Σχεδιάζεται πίσω από τα εικονίδια μέσα στη σκηνή του wallpaper. Έχει κεντράρισμα, ρυθμιζόμενη θέση και διαστάσεις, ξεχωριστή παλέτα για κάθε visualization, και στοιχεία κομματιού από τα Windows όταν είναι διαθέσιμα. Καλύπτει τη στατική εικόνα και τις σκηνές που σχεδιάζει το Opsis.

Το νέο περιβάλλον έχει ελληνικά και αγγλικά. Οι υπόλοιπες γλώσσες της 2.6.0 παραμένουν διαθέσιμες στις υπάρχουσες λειτουργίες.

Η χειροκίνητη επιλογή ορίζει το φόντο και διατηρεί την τοποθεσία καιρού.

## Αλλαγές 2.7.7.2403 (πηγαίος κώδικας, build Windows σε εκκρεμότητα)

- Πριν από εισαγωγή ZIP wallpaper προβάλλεται λίστα αρχείων, μέγεθος και προειδοποίηση για HTML/JavaScript. Απορρίπτονται ύποπτες διαδρομές, σύνδεσμοι, διπλά ονόματα και υπερβολικά μεγάλα πακέτα. Η εξαγωγή γίνεται πρώτα σε προσωρινό φάκελο και ολοκληρώνεται μόνο αν περάσουν όλα τα βήματα.
- Η αλλαγή προφίλ διατηρεί στιγμιότυπο ρυθμίσεων και widgets ώστε σε σφάλμα να επιχειρείται επαναφορά της προηγούμενης κατάστασης. Οι παγκόσμιες επιλογές γλώσσας/θέματος δεν αντικαθίστανται από παλιό προφίλ.
- Οι αμετάβλητες ρυθμίσεις δεν ξαναγράφονται στον SSD. Το εφεδρικό αρχείο JSON ενημερώνεται ατομικά, όπως και η ανάκτηση.
- Το Weather Wallpaper διατηρεί την τελευταία έγκυρη παρατήρηση σε προσωρινή απώλεια σύνδεσης και εμφανίζει πηγή, ηλικία παρατήρησης και προειδοποίηση για παλιά δεδομένα. Νέα πόλη δεν κληρονομεί θερμοκρασία προηγούμενης πόλης.
- Νέος headless έλεγχος για ZIP ασφαλείας και αυτοματοποιημένοι έλεγχοι JavaScript. Προετοιμασμένο GitHub Actions workflow για Windows build, self-test, έλεγχο UI και SHA-256 του installer. **Η εκτέλεση Windows build / installer / UI audit δεν επιβεβαιώθηκε σε αυτό το περιβάλλον.**

## Αλλαγές 2.7.7.2402

Στο δεξί κλικ σε κενό σημείο της επιφάνειας, το κλασικό μενού εμφανίζει **Opsis → Νέο DeskContainer** και **Opsis → Κινούμενο wallpaper → Προηγούμενο, Επόμενο, Παύση / συνέχιση, Διακοπή**. Στα Windows 11, άνοιξε το κλασικό μενού με **Shift + δεξί κλικ** ή **Εμφάνιση περισσότερων επιλογών**. Τα χειριστήρια αναπαραγωγής αφαιρέθηκαν από τη συλλογή.

Το συμπαγές μενού των Windows 11 22H2 και νεότερων χρησιμοποιεί τη δήλωση `desktop10:ItemType` με τύπο `DesktopBackground`. Με πιστοποιητικό υπογραφής έμπιστο στα συστήματα προορισμού, ο υπεύθυνος του build μπορεί να εκτελέσει το `installer/explorer/Build-ExplorerIdentity.ps1` με το publish directory και το αποτύπωμα του πιστοποιητικού πριν συσκευάσει το εκτελέσιμο. Το `Register-ExplorerIdentity.ps1` συνδέει το υπογεγραμμένο MSIX με τον φάκελο εγκατάστασης για τον τρέχοντα χρήστη. Το συμπαγές μενού εμφανίζει τις τέσσερις εντολές κάτω από την επικεφαλίδα «Κινούμενο wallpaper» μέσα στο Opsis, σύμφωνα με τον περιορισμό του Explorer σε ένα επίπεδο υπομενού.

Η συλλογή έχει έξι νέα τοπία δάσους, πόλης, λίμνης, φιόρδ και υφάλου με κινούμενη ομίχλη, φώτα, αντανακλάσεις και σμήνη πουλιών ή ψαριών. Τα υπόλοιπα φόντα χρησιμοποιούν ανανεωμένη τονική απόδοση. Τα πλαίσια και τα κουμπιά διατηρούν τα χρώματα του επιλεγμένου θέματος.

Για να μεταγλωττίσεις έναν ενιαίο installer από τον πηγαίο κώδικα, εκτέλεσε σε Windows με .NET 11 SDK και Inno Setup 7:

```powershell
dotnet publish .\Opsis.Studio.csproj -c Release -r win-x64 --self-contained false -o .\publish
& "$env:ProgramFiles\Inno Setup 7\ISCC.exe" .\installer.iss
```

Ο οδηγός εγκατάστασης παράγεται στον φάκελο `Output`. Ο διακόπτης `/DExternalPayload` στο ISCC επιλέγει την παραλλαγή που διαβάζει τα αρχεία από τον φάκελο `payload` δίπλα στο εκτελέσιμο.

## Αρχαία Αθήνα και οργάνωση επιφάνειας

- **Wallpaper → Λειτουργία → Αρχαία Αθήνα**. Το τοπίο έχει τέσσερις φάσεις φωτισμού από τις εικόνες αναφοράς. Το **Αυτόματα** ακολουθεί την ανατολή και τη δύση της Αθήνας, με ομαλές μεταβάσεις. Από τον **Φωτισμό** μπορείς να κρατήσεις σταθερή μία φάση. Η σκηνή λειτουργεί και στον χρονοπρογραμματισμό Wallpaper.
- **DeskContainers → Διατάξεις και οργάνωση αρχείων**. Δημιούργησε έξυπνο container από τοπικούς φακέλους ή όρισε κανόνες ταξινόμησης για τα αρχεία της επιφάνειας εργασίας. Η ταξινόμηση ενημερώνει τις αναφορές στα containers. Τα αρχεία παραμένουν στους φακέλους τους.
- **DeskContainers → Διαχείριση κανόνων αρχείων**. Πρόσθεσε, επεξεργάσου, ενεργοποίησε και βάλε σε σειρά τους κανόνες. Μπορείς επίσης να επιλέξεις προεπιλεγμένο προορισμό. Χρησιμοποίησε τα διαθέσιμα πρότυπα για να συμπληρώσεις τις συνθήκες.
- **DeskContainers → Προβολή αρχείων**. Κάθε container έχει επιλογή εικονιδίων, λίστας ή λεπτομερειών. Η προβολή λεπτομερειών εμφανίζει μέγεθος και ημερομηνία τροποποίησης όταν υπάρχει αρκετό πλάτος.
- **DeskContainers → Εξαγωγή τρέχουσας διάταξης**. Αποθηκεύει την τρέχουσα διάταξη, τα φίλτρα και τους κανόνες σε JSON. Το αρχείο περιλαμβάνει τις διαδρομές των τοπικών φακέλων και συντομεύσεων.
- **DeskContainers → Διάταξη ανά συνδυασμό οθονών**. Σύνδεσε ένα αποθηκευμένο στιγμιότυπο με τις τρέχουσες οθόνες για αυτόματη εναλλαγή όταν επιστρέφει αυτός ο συνδυασμός.
- **DeskContainers → Προσωρινή εμφάνιση containers**. Με Ctrl+Alt+Shift+Space τα ορατά containers έρχονται μπροστά από τα παράθυρα. Μπορείς να ενεργοποιήσεις το σκούρο φόντο και να κλείσεις την προβολή με Esc.
- **DeskContainers → Εισαγωγή διατάξεων JSON**. Η προεπισκόπηση επιτρέπει την επιλογή συμβατής διάταξης από ένα αρχείο ρυθμίσεων ή αντίγραφο ασφαλείας. Τα **Στιγμιότυπα διάταξης** αποθηκεύουν και επαναφέρουν τις δικές σου διατάξεις.

Για επαναληπτικές μετρήσεις σε Windows, από δοκιμαστικό λογαριασμό ή VM με .NET 11 Desktop Runtime:

```powershell
$env:OPSIS_E2E = '1'
$env:OPSIS_APPDATA = Join-Path $env:TEMP ('OpsisAudit-' + [guid]::NewGuid())
$env:OPSIS_AUDIT_NOCLICK = '1'

Start-Process ".\Opsis.Studio.exe" -ArgumentList "--ui-audit", "OpsisAudit" -Wait
```

Το `ui-resources.json` περιέχει δείγματα CPU, μνήμης, handles και GDI/USER objects του Opsis. Η αναφορά αφορά την κύρια διεργασία Opsis. Το `ui-audit.md` και τα PNG καταγράφουν τα αποτελέσματα πλοήγησης και την εμφάνιση. Για συγκεκριμένο skin όρισε `OPSIS_AUDIT_SKIN` σε `Classic`, `Studio`, `Atlas`, `Inspector`, `Index` ή `Split` πριν από την εκτέλεση.

## Μεταγλώττιση

Από τον φάκελο του πηγαίου κώδικα, με το .NET 11 SDK:

```powershell
dotnet publish .\Opsis.Studio.csproj -c Release -r win-x64 --self-contained false -o .\publish
```

Στο Linux χρειάζεται επιπλέον `-p:EnableWindowsTargeting=true` για τη μεταγλώττιση του πακέτου Windows. Τα DLL στον κατάλογο `lib/` προέρχονται από το πακέτο Windows x64 της 2.6.0 και περιλαμβάνουν τις βιβλιοθήκες UI, GPU glass, DeskContainers και το συμβόλαιο προσθέτων. Το `src/` περιέχει τον πηγαίο κώδικα της εφαρμογής και των νέων αλλαγών. Τα κείμενα άδειας και οι αναφορές προέλευσης υπάρχουν στο πακέτο.

Επαληθεύτηκαν η μεταγλώττιση Windows x64, τα αρχεία του πακέτου, η διαδρομή φόρτωσης του wallpaper, και η λογική του visualizer για στατική και κινούμενη σκηνή, χρώματα, μέγεθος και θέση. Εκκρεμούν οι δοκιμές σε πραγματική επιφάνεια εργασίας Windows για εμφάνιση, σύνδεση με Explorer, hotkeys και κλείδωμα.


### Έλεγχος εμφάνισης της 2.7.7.2402 σε Windows

Από τα αρχεία του build της εφαρμογής, μπορείς να τρέξεις τον έλεγχο με προσωρινές ρυθμίσεις. Για σκούρο θέμα άλλαξε το `Light` σε `Dark`. Το `OPSIS_AUDIT_SKIN` επιλέγει skin, ενώ το `OPSIS_AUDIT_WIDTH` ζητά πλάτος παραθύρου σε pixel.

```powershell
$run = Join-Path $env:TEMP ("opsis-ui-audit-" + [guid]::NewGuid())
$env:OPSIS_APPDATA = Join-Path $run "profile"
$env:OPSIS_E2E = "1"
$env:OPSIS_AUDIT_LANGUAGE = "el"
$env:OPSIS_AUDIT_THEME = "Light"
$env:OPSIS_AUDIT_NOCLICK = "1"
$env:OPSIS_AUDIT_RESOURCE_CYCLES = "3"
Start-Process .\Opsis.Studio.exe -ArgumentList @("--ui-audit", ('"' + (Join-Path $run "results") + '"')) -Wait
```

Ο φάκελος `results` έχει στιγμιότυπα ανά καρτέλα, μεγέθη χειριστηρίων, DPI, λεζάντες για οπτική επαλήθευση και μετρήσεις πόρων της διεργασίας του Opsis. Ο έλεγχος του WebGL εκτελείται με `node --test tests/WebGLRecovery.test.cjs`.

### Build του installer στα Windows

Το BAT χρησιμοποιεί το .NET 11 SDK και το Inno Setup 7. Η επιλογή 2 δημιουργεί το πακέτο στον φάκελο Output. Για προσαρμοσμένη εγκατάσταση του Inno Setup, το BAT δέχεται την πλήρη διαδρομή του ISCC.exe και μέσω της μεταβλητής περιβάλλοντος ISCC. Αν λείπουν τα Visual C++ Build Tools, το build χρησιμοποιεί το κλασικό μενού του Explorer. Στα Windows 11 αυτό είναι διαθέσιμο από την «Εμφάνιση περισσότερων επιλογών».

### Απόδοση και αδράνεια στο .NET 11

Το global.json επιλέγει σταθερό SDK 11.0.100 ή νεότερο της σειράς 11.0. Το wallpaper μειώνει την ανάλυση καμβά όταν τα αργά καρέ επιμένουν και την επαναφέρει σταδιακά μόλις υπάρχει περιθώριο. Η ρύθμιση αυτόματης απόδοσης και η παράκαμψη ανά λειτουργία ελέγχουν αυτή την προσαρμογή. Η παύση απομακρυσμένης συνεδρίας ρυθμίζεται από τις επιλογές απόδοσης.

Ο έλεγχος Windows γράφει το ui-resources.json. Περιλαμβάνει CPU της εφαρμογής ανά χρονικό διάστημα, αθροιστικό χρόνο CPU και private bytes ανά διεργασία WebView2, χρόνο πρώτης ζωγραφικής κάθε σελίδας, δείγματα πριν και μετά το κλείσιμο των ενσωματωμένων widgets, GDI/USER handles στις αλλαγές skin και αδράνεια στο tray. Τα P95/P99 αφορούν τις τελευταίες έως 300 αποστάσεις μεταξύ καρέ κάθε ενεργού καμβά. Χωρίς ενεργό wallpaper δεν υπάρχουν δείγματα καρέ. Οι συγκρίσεις RAM και handles αποκτούν νόημα όταν η ίδια αύξηση επαναλαμβάνεται μετά την προθέρμανση.
