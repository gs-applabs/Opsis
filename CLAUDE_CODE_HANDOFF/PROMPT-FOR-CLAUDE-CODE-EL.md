# Έτοιμη εντολή για Claude Code

Ανάλαβε τον τεχνικό έλεγχο και την ολοκλήρωση του OPSIS Desktop Customization **2.8.0.2500** από αυτόν τον φάκελο. Διάβασε πρώτα το `CLAUDE.md`, `CLAUDE_CODE_HANDOFF/START-HERE-EL.md`, `TASKS-AND-ACCEPTANCE-EL.md`, `QA-WINDOWS-RUNBOOK-EL.md`, το αρχικό `ROADMAP-100-EL.md` και το `IMPLEMENTATION-100-STATUS-2.8.0.2500.json`. ΜΗΝ υποθέσεις ότι η ένδειξη «υλοποιήθηκε» σημαίνει ότι χτίστηκε ή δοκιμάστηκε.

1. Χαρτογράφησε όλο τον πηγαίο κώδικα, βρες compile bugs, ύποπτα API, τρύπες ασφαλείας, αλλοίωση παλιών λειτουργιών, επιδόσεις/idle και εσφαλμένες εξαρτήσεις. Σύγκρινε με το ανακατασκευασμένο Git ιστορικό και επιβεβαίωσε τι πραγματικά άλλαξε R3→R10.
2. Συμπλήρωσε τα επτά μερικά σημεία (#12, #17, #20, #24, #32, #40, #97), χωρίς να θεωρήσεις in-process manifest πραγματικό sandbox και χωρίς ψευδείς εγγυήσεις απόκρυψης ειδοποιήσεων τρίτων.
3. Εφάρμοσε .NET 11 Windows build, όλες τις δοκιμές Node/.NET/WinForms/WebView2/installer και πραγματικά E2E συμβατότητας με Crawler/Χρονικολόγιο/Appearance/Media Suite. Τα plugin DLL των Crawler και Χρονικολογίου πρέπει να έχουν AssemblyVersion+FileVersion **1.0.0.0**· η κοινή ABI μπορεί να έχει διαφορετική σταθερή έκδοση.
4. Ολοκλήρωσε τα release gates #92, #93, #99. Διόρθωσε και εκτέλεσε τα υπάρχοντα GitHub Actions workflows στο ακριβές source R10 ή στο επόμενο commit με διορθώσεις, όχι σε παλιό branch. Δοκίμασε Windows 11 πραγματικό installer, upgrade, side-by-side και uninstall με απομονωμένες ρυθμίσεις.
5. Παράδωσε διορθωμένο source, ελεγμένο installer μόνον αν όντως δημιουργηθεί, πλήρη δοκιμαστικά αποτελέσματα/σφάλματα, SHA-256 και μία αναλυτική τελική αναφορά για **όλα τα 100 σημεία**.

Μην τροποποιείς τυφλά το αρχικό GitHub `main`, μην αποκρύπτεις αποτυχίες, μην παρουσιάζεις συνθετικά Git commits ως αυθεντικά και μην παραλείπεις checks ασφάλειας για να επιτύχεις «πράσινο» αποτέλεσμα.
